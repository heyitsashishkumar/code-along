# 005 · Your project

The code at the end of **video 5** of *LWC & Apex from Zero: Code Along*, "The Extension Pack, Your Project, and Connecting Your Org". Type it yourself first, then compare your files with these.

## What's in it

The project `miller-desk` exactly as `SFDX: Create Project` makes it (the Standard template), before any code of ours. Every video from here on adds to this one project.

`force-app/main/default/` is where your components and classes will go. VS Code makes its folders empty, and git can't keep empty folders, so they aren't shown here. They come back when you make your own project.

## Connect your org

Run `SFDX: Authorize an Org` from the command palette (`⇧⌘P` on a Mac, `Ctrl+Shift+P` on Windows), choose **Project Default**, give it the alias `desk-org`, and log in to your free Developer Edition org in the browser that opens.
